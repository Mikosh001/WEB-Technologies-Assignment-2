# Advanced CSS Assignment 2

This static website completes the Flexbox and CSS Grid tasks in Assignment 2. Tasks 1–4 each have a separate page and stylesheet. Task 0 is the shared Flexbox navbar on every page:

- Task 0: shared navbar — Flexbox header with a logo on the left and navigation links on the right; no separate navbar page.
- Task 1: `index.html` / `cards.css` — three equal-height cards with images, titles, text, buttons, gaps, and a hover effect.
- Task 2: `grid-layout.html` / `grid-layout.css` — header, sidebar, main content, and footer placed with named CSS Grid areas.
- Task 3: `gallery.html` / `gallery.css` — nine local images in a three-column grid with caption overlays on hover and keyboard focus.
- Task 4: `portfolio.html` / `portfolio.css` — Flexbox navigation, a two-column Grid main section, and Flexbox project cards.

## Links

## Run locally

Open `index.html` in a web browser. No build step, dependencies, or server are required. Use the navbar to visit the other pages.

## Publish

Upload this folder as the root of a GitHub repository, then enable GitHub Pages from the repository's main branch and root folder. The website starts at `index.html`.
